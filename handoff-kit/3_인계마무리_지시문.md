# 3. 인계 마무리 지시문 — 한도가 다 되어 갈 때

**언제:** 사용량이 80~90%쯤 됐거나, 오늘 작업을 끝낼 때. 한도에 완전히 걸리면 아무것도 시킬 수 없으니 **미리** 보내세요.
**짧게:** 그냥 `인계 준비`라고만 보내도 됩니다. (AGENTS.md 기록 규칙에 같은 내용이 들어 있음)

~~~~text
[인계 준비]

하던 작업을 지금 상태에서 멈추고 다음을 해줘. 새로운 작업은 시작하지 마.
1. 작업 중이던 코드가 있으면: 돌아가는 상태면 commit, 아니면 "WIP:" 를 붙여 commit 하고
   현황판 "위험·주의"에 무엇이 미완성인지 적어.
2. docs/handoff/00_현황판.md 를 덮어써서 갱신해:
   - 지금 위치: 다음 사람이 바로 이어갈 수 있게 파일·함수 이름과 멈춘 지점까지
   - 다음 할 일 3개
   - 내 답을 기다리는 질문
   - 최근 바뀐 것에 오늘 3줄
3. 이번 세션에서 내가 확정한 결정은 01_결정기록, 새로 확인한 사실은 02_알아낸것, 
   작업 내역은 log 에 한 줄씩 추가해.
4. git push 까지 하고, push 결과와 현황판 전문을 보여줘.
~~~~
