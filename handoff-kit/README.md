# 인계 키트 (handoff-kit)

한도에 걸리거나 계정·플랫폼을 바꿔도, 다른 에이전트가 프로젝트를 **설명 없이 바로 이어받게** 하는 지시문 모음입니다.

## 어떤 지시문을 언제 쓰나

| 상황 | 쓸 파일 |
|---|---|
| 새 프로젝트에 인계 체계를 처음 만들 때 | [1_설치_지시문](1_설치_지시문.md) |
| 이미 긴 기록 문서(백서)가 있는 프로젝트 | [4_기존백서_이전_지시문](4_기존백서_이전_지시문.md) |
| 한도가 80~90%쯤 됐거나 오늘 작업을 끝낼 때 | [3_인계마무리_지시문](3_인계마무리_지시문.md) — 또는 그냥 `인계 준비` |
| 세컨 계정·다른 플랫폼에서 이어서 시작할 때 | [2_이어받기_지시문](2_이어받기_지시문.md) |

각 파일의 회색 상자 안 내용을 **통째로 복사**해서 에이전트에게 붙여넣으면 됩니다.

## 설치하면 프로젝트에 생기는 것

```
프로젝트/
├── AGENTS.md              ← 모든 에이전트가 처음 읽는 안내서 (Codex·Cursor 등이 자동으로 읽음)
├── CLAUDE.md              ← "AGENTS.md를 읽어라" 한 줄 (Claude용)
├── GEMINI.md              ← 같은 한 줄 (Gemini용)
└── docs/handoff/
    ├── 00_현황판.md        ← 40줄 이내. 새 에이전트는 이것만 읽고 시작
    ├── 01_결정기록.md      ← 사용자가 확정한 결정과 이유
    ├── 02_알아낸것.md      ← 확인된 사실·원인·함정
    └── log/2026-10.md      ← 경과 로그 (월별, 한 줄 150자)
```

## 왜 이렇게 하나 (기존 백서 방식과 차이)

| | 기존: 백서 한 파일 | 인계 키트 |
|---|---|---|
| 새 에이전트가 읽는 양 | 전체 (100KB 이상) | 현황판 40줄 + 안내서 |
| 기록 시점 | 매 턴 강제 (훅) | 진전·결정·마무리 때 |
| 다른 플랫폼 | 훅은 Claude에서만 작동 | 일반 파일이라 어디서나 |
| 이어받는 경로 | 같은 PC 폴더 | GitHub (push/pull) |

## 꼭 지킬 것

1. **한도가 완전히 막히기 전에** `인계 준비`를 보내세요. 막힌 뒤에는 아무것도 시킬 수 없습니다.
2. 이어받으려면 프로젝트가 **GitHub에 push되어 있어야** 합니다. 같은 PC에서 다른 에이전트로 폴더를 열 때는 push 없이도 됩니다.
3. 비밀번호와 API 키는 어떤 기록 파일에도 적지 않습니다.
