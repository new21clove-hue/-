# 2. 이어받기 지시문 — 다른 계정·다른 에이전트에서 시작할 때

**언제:** 한도에 걸려서 세컨 계정이나 다른 플랫폼(Codex, Cursor, Gemini 등)으로 같은 프로젝트를 열었을 때, 첫 메시지로 붙여넣습니다.
**전제:** 그 프로젝트에 `1_설치_지시문`으로 인계 체계가 이미 만들어져 있어야 합니다.

~~~~text
[작업 이어받기]

다른 에이전트가 하던 작업을 이어받는다.
1. git pull 로 최신 상태를 받아.
2. AGENTS.md 와 docs/handoff/00_현황판.md 만 먼저 읽어. 다른 파일은 필요할 때만.
3. 아직 작업하지 말고, 나에게 아래만 5줄 이내로 보고해:
   - 이해한 현재 위치
   - 다음 할 일 1순위
   - 내 답을 기다리는 질문
   - 현황판과 실제 코드·git 기록이 다른 점이 있으면 그것
4. 내가 "진행"이라고 하면 시작해. 기록은 AGENTS.md 의 기록 규칙을 따른다.
~~~~
